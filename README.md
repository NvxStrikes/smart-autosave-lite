## What It Does

Smart AutoSave+ Lite silently saves a backup of your Blender project on a timer you control. No popups, no interruptions — just quiet protection running in the background.

Every Blender artist has been here:
> *"It's 2 AM. I've been working for 3 hours. Blender just crashed."*

This addon makes sure that never costs you your work.

## Features

- ✅ Auto-save on a custom interval (1–60 minutes)
- ✅ Force save backup instantly with one click
- ✅ Keeps your last 3 backups automatically
- ✅ Open your backup folder directly from Blender
- ✅ Works on Windows, Mac & Linux
- ✅ Blender 4.4 – 5.0+ compatible
- ✅ 100% free, no strings attached

## Installation

1. Download `autosave_lite` from this repo
2. Open Blender → Edit → Preferences → Add-ons
3. Click **Install** and select the downloaded file
4. Enable **Smart AutoSave+ Lite** from the list
5. Find it in your **N-Panel** (press `N` in the viewport) under the **Smart AutoSave+ Lite** tab

---

## Usage

1. Save your `.blend` file first (Ctrl+S)
2. Set your preferred interval in the panel
3. That's it — backups save automatically to an `autosaves/` folder next to your `.blend`
